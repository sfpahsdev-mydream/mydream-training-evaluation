# AGENTS.md

## Scope

This guidance applies to the MyDream training/evaluation Python project.

Use this repository for preprocessing, model training/evaluation scripts,
generated reports, transfer bundles, and Android parity sample generation.

## Local Backup

Keep personal sleep exports and generated model outputs under:

```text
local_backup/
```

This folder is local-only and must stay out of Git.

Do not move, delete, or commit files from `local_backup/` unless the user
explicitly asks.

Current grouped backup:

```text
local_backup/mydream_current/
```

See:

```text
local_backup/mydream_current/README_LOCAL_BACKUP.md
```

## Data Safety

Do not commit personal sleep exports, generated CSV files, model artifacts,
transfer bundles, or evaluation outputs.

These are expected to remain ignored:

- `*.jsonl`
- `*.ndjson`
- `out/`
- `colab_result/`
- `local_backup/`
- `*.csv`
- `*.zip`
- `*.joblib`
- `*.pkl`
- `*.onnx`
- `*.tflite`

## Work Rules

- Treat `out/verify_week_period_profile/` as the current canonical local output root.
- Use Colab or a TensorFlow-enabled server for TensorFlow training/conversion.
- Keep Android parity samples generated by `create_android_parity_sample.py` aligned with the Android assets.
- Update `README.md` or `FUNCTION_REFERENCE.md` when adding a new script or changing script usage.
